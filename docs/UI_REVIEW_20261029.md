- Floor-plan asset positions now use the same execution feedback as the 3D view. A completed transfer visibly places the apple on the destination table. Map labels remain readable over light objects.
- Rebuilt production frontends and all four Linux/Windows server/desktop installer ZIPs in `dist/installers`.
