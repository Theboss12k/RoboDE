# Global robot setup and RTX installers — 28 October 2026

Global configuration now adds reusable robots independently of projects: import a declarative definition or start from a template, review it, choose/create a physical or virtual control adapter, and test through simulated transport. Project instances select the global robot and adapter; their pairing is saved on the server with the adapter review hash. Global controls cannot arm hardware or create project instances. See [robot library guide](ROBOT_LIBRARY.md).

Bundled definitions use writable data copies for shared limit edits. The registry deduplicates those copies and validates factory and project initial states before accepting changed limits. Reviewed/tested compatible adapters are required for project assignment. Isolated adapter tests initialize from the selected instance's saved joints, while live connections remain read-only until explicitly armed. Instance binding changes invalidate compiled snapshots without rewriting historical runs. Global wizard closure waits for its simulated controls to stop and disconnect.

Four clean bootstrap ZIP installers are under `dist/installers`: hosted server and local Electron desktop, each for Ubuntu x64 and Windows 11 x64. The server serves both authenticated React apps through one planning/runtime authority. Desktop listeners are loopback-only. Python 3.12 and a compatible NVIDIA driver/GPU are prerequisites; optional setup downloads Isaac 6.2 into a separate environment, and desktop setup downloads and verifies the pinned official Electron release. The installer retains virtual-environment executable paths and accepts the official checksum manifest's binary-file `*filename` format. Data is separate from versioned application files. See [installer guide](../installers/README.md).

The Business App includes a self-contained offline photo-capture page that exports a portable ZIP. The IDE imports these captures in Environment without changing the active scene. Photos still require reconstruction; USDZ imports require review of metric scale, alignment and collision assets before native deployment. NuRec reconstruction remains a separately configured runtime.
