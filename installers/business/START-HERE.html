RoboDE Business

Your workspace on your computer or phone.

1. Connect to your server

First install the RoboDE Server edition. Ask its operator for the Business App URL and your workspace access code. The server runs planning and simulation for you.

2. Install on your device

Once signed in, select Install app in RoboDE Business.

  • Android / Chrome: use Install app or the browser menu → Install app / Add to Home screen.
  • iPhone / iPad / Safari: Share → Add to Home Screen → Open as Web App, if shown.
  • Windows / Linux / macOS: Chrome or Edge → Install app; macOS Safari → File → Add to Dock.

No Python or GPU is needed on this device. Use HTTPS for camera and speech access. Commands require the RoboDE server to be running.

Offline room captures

Open offline room capture, take or select photographs, then export the capture ZIP. Upload this file manually in the desktop IDE's Environment workspace. A photo capture requires reconstruction before it becomes a simulated room.

For a desktop shortcut you can also run install-business.command (Mac), install-business.ps1 (Windows), or install-business.sh (Linux). These optional shortcut installers use Python 3. No account credentials are stored in the shortcut.
