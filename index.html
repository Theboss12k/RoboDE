Plan, control and command robots in plain English.

RoboDE is a robotics IDE. A Planner LLM turns an instruction into robot tasks, a Task LLM turns each task into robot commands, and every motion is checked before it runs in NVIDIA Isaac Sim on a cloud GPU.

From one sentence to a verified simulation run

Recorded on the RoboDE server running entirely on a Google Cloud GPU VM, connected live to Isaac Sim.

STEP 1

Choose a Planner LLM and a Task LLM

The two roles can use different models and providers. Here the Planner is Nemotron 3.5 Bolt on the GPU VM and the Task LLM is Nemotron 3 Nano 30B. Each plan, and each Business App command, can override them.

STEP 2

The Planner LLM writes the tasks

From the instruction “move the apple from Table1 to Table2”, Nemotron 3.5 Bolt produced nine ordered tasks for arm_01, each with its dependencies. Tasks stay editable before anything is converted or run.

STEP 3

Connect Isaac Sim and start recording

The Environment workspace connects to the Isaac Sim worker on the GPU VM, reads the live scene and resets it. A native Isaac camera recording starts at 1280×720, 10 fps.

STEP 4

Validate, then run it live

Validation compiles the plan into trajectories and checks reach, joint limits and collisions. Run sends it to Isaac Sim; the 3D view shows execution feedback as each task completes.

STEP 5

Every run is kept and verified

Each run reopens its exact compiled revision. Postconditions are verified from the state Isaac Sim reports, and the log lists every task with a timestamp.

Project simulator · Isaac Sim physics worker

Drive the robots in real time

Joint sliders stream targets to the GPU scene, and the measured joint values come back from Isaac's articulation. In the recording, each move was confirmed against that feedback before the next one started.

Safety check in actionOne scripted move would have lowered arm_02 into a table. RoboDE refused it with “Link intersects table at sample 30” and stopped that control session before anything moved.

Before anything moves

LLM output is never run unchecked

Schema and repair

Task LLM output is validated against the robot's command catalog, normalized, and repaired once if the JSON is malformed. Anything else is rejected with a specific error.

Kinematics

Commands become trajectories through inverse kinematics, with analytic and serial_chain_dls_v1 solvers.

Limits and collisions

Joint limits, robot-to-robot, table and object collisions are checked on every sample of every trajectory.

Postconditions

After a run, the result is verified from observed simulator state, and each compiled revision is immutable.

All four rejected unreachable poses, unknown actuators and joint-limit violations. All four failed the three adapter-generation tests. Only Bolt passed the 30 cm object lift, and it was the most reliable Planner on the live Isaac project.

One codebase, several ways to run it

RoboDE

The standard edition. Desktop app with local calculations, or a team server with the browser IDE and Business App.

npm run server:start
NVIDIA edition

RoboDE for NVIDIA

NVIDIA accents and a first-boot setup that defaults to Isaac Sim on a Nebius GPU VM and Nemotron on Nebius Token Factory. Other simulators and models stay available.

npm run server:start:nvidia

Business App

A phone-friendly companion: named workspace assets, natural-language and voice commands with model choice, and room photos.

npm run business:start
